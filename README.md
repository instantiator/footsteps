# Christmas Game 2025

This game is built on Footsteps, a puzzle game engine and interface (a Vite + React + TypeScript app).

See the [documentation](https://instantiator.dev/footsteps/docs/), including the [API reference](https://instantiator.dev/footsteps/docs/tsdoc/) generated from the TSDoc comments in `src/`.

To read the documentation locally, with live reload, run `npm run docs:dev`. Regenerate the API reference with `npm run docs:api` whenever `src/` changes.
