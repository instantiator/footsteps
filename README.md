# 👣 Footsteps

Footsteps is a game engine for home-spun, escape room style puzzle adventures.

[![Quality gate](https://github.com/instantiator/footsteps/actions/workflows/check.yaml/badge.svg)](https://github.com/instantiator/footsteps/actions/workflows/check.yaml)

## Getting started

```bash
# clone this repository
git clone https://github.com/instantiator/footsteps.git

# enter the repository
cd footsteps

# install pre-requisites
npm install

# start footsteps
npm run dev
```

## About Footsteps

Footsteps is a React application written in Typescript and built with Vite.
