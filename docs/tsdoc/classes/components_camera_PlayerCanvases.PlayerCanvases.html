    Class PlayerCanvases

    Gives each player in a frame their own canvas, so each can be layered and moved separately, for as long as the player is there.

    The canvas given is only a reference: it isn't shown, and it never moves, so it stays the thing to measure against when a player's canvas is falling off the screen. Players' canvases look as it does, but take nothing from each other, so a new player doesn't inherit another's effects.
