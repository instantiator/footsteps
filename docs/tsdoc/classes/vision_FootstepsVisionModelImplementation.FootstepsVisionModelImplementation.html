    Class FootstepsVisionModelImplementationAbstract

    A vision model that finds players in camera frames, whatever library runs it.

    Each implementation gives the same result: a silhouette mask and key points per person, in our own body parts. The queries work on any frame, so they also answer for frames a worker produced.
