    Class PlayerMonitor

    Turns one player's segmentation frames into interaction events.

    Events are edge-triggered: an interaction fires when it begins, not on every frame it holds. The first frame only records what already holds, so a player who is already inside an element when the monitor starts (as a display fades in) must move into it again. The monitor also follows the player's feet for jumps (JumpDetector). When they land, it fires jump for an element their feet were on both at take-off and at landing, jump-from for one they took off from, and jump-onto for one they landed on.
