## Landing page modifications

At current time, the landing page shows:

- "Footsteps" as a top level heading
- the current path (eg. `/footsteps/`)
- "Local repository" heading
  - Local repository status
  - Each game in the local repository as a list item
    - All of its attributions as a sub-list
- An "Attributions" heading
  - A list of the application attributions
- A "Dependencies" heading
  - A list of all dependencies

![landing page](./illustrations/000.04.00%20-%20landing%20page.png)

### Game listings

Games should have:

- A title (as currently)
- A description (new)
- A resource selected as the game graphic (new)

Add these properties to the model, and update the existing games to be compliant.

Each game should be listed as a game tile:

![proposed game tile](./illustrations/000.04.00%20-%20proposed%20game%20tile.png)

- The outer box should have an outline with curved corners
- Box should contain:
  - Game title
  - Game id
  - A game
  - A game graphic as its background

- Game tiles should appear in a grid
- Grid tiles should be added horizontally, wrapping onto the next row when each row is filled
- Grid tiles should all be the same size
- Grid tiles should have a sensible size set for the display - ie. some number of px that leaves enough space for a game title and description

### Attributions

Attributions should have a subheading for "Footsteps" (ie. the application level attributions), and then a subheading for each game - and list each game's attributions under its heading there.
