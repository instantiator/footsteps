## Context

The home page (`src/Home.tsx`) is one long column: the games, then Setup and design, then the attributions. To reach
the later sections you scroll, and the page doesn't fit a laptop screen. The feedback asks for:

- tabs, so each section is one click away;
- a page that fits a laptop screen without scrolling;
- a 👣 icon in the title, at the text's size;
- a footer saying Footsteps is open source under the MIT licence, linking to the licence and the GitHub repository.

Tile sizing stays as it is.

The repository has no LICENSE file, so GitHub's licence link points at `generate-license-report.sh` instead. The user
confirmed MIT. Every dependency in `src/assets/license-report.json` is under a permissive licence, so MIT is
compatible:

- MIT ×37, Apache-2.0 ×7, BSD-3-Clause, 0BSD, Unlicense;
- dompurify is (MPL-2.0 OR Apache-2.0), and its Apache-2.0 option is compatible.

## Layout (from the mock-up)

```text
┌ 👣 Footsteps ─────────────────────────────────────────┐   title panel
├ [Local repository] [Setup and design] [Attributions]  ┤   tabs
│ ┌───────────────────────────────────────────────────┐ │
│ │ the chosen tab's content; only this panel scrolls │ │   tab panel: fills the rest
│ └───────────────────────────────────────────────────┘ │
├ Footsteps is an open source product, released under the MIT license. Source code at: instantiator/footsteps ┤   footer
└───────────────────────────────────────────────────────┘
```

- **Page:** a full-height flex column, `100dvh`: the title, the tabs, the panel (`flex: 1; min-height: 0;
overflow: auto`) and the footer. The page itself never scrolls, so it fits a laptop. When a tab's content is long,
  only the panel scrolls.
- **Title:** `<h1><span aria-hidden="true">👣</span> Footsteps</h1>`. The emoji inherits the heading's font size, so
  it's the same size as the text.
- **Tabs:** an accessible tab set.
  - `role="tablist"`, with a `role="tab"` button for each tab and one `role="tabpanel"`.
  - `aria-selected` and `aria-controls` link each tab to the panel.
  - Arrow keys, Home and End move between the tabs, and only the chosen tab is in the Tab order.
  - The tabs are **Local repository**, **Setup and design** and **Attributions**.
- **Tab memory (user):** the URL hash records the chosen tab (`#local-repository`, `#setup-and-design`,
  `#attributions`), replaced rather than pushed, so a reload or a shared link opens that tab and Back isn't filled
  with tab changes. No hash, or an unknown one, opens Local repository. The page is prerendered on the first tab,
  then switches to the hash's tab after hydration, which may flash briefly.
- **Tab content:**
  - **Local repository:** `LocalListing` as now: the same tiles and grid, and the status line.
  - **Setup and design:** the two links with their descriptions, as now.
  - **Attributions:** the Dependencies link first, then `Attributions`, as now.
- **Footer:** "Footsteps is an open source product, released under the
  [MIT license](https://github.com/instantiator/footsteps/blob/main/LICENSE). Source code at:
  [instantiator/footsteps](https://github.com/instantiator/footsteps)." In debug mode, the base path moves from under
  the title to the end of the footer.
- **Style:** the landing page's palette (`#dce8f5` behind, white panels with `#22303c` text), with the selected tab
  joined to the panel as in the mock-up. A new `src/HomePage.css`; `.game-panel` from `GamePanel.css` is reused for
  the title and the panel.

### Components

- **`src/components/landing/Tabs.tsx`** (new): a small, generic, accessible tab set,
  `<Tabs tabs={[{ id, label, content }]} />`. It keeps the chosen tab in the URL hash with `useLocation` and
  `useNavigate` (`replace: true`). It's the only tab set in the app, but keeping the ARIA and keyboard handling in
  one place makes it testable on its own.
- **`src/Home.tsx`:** the title, `<Tabs>` with the three sections, and the footer. `GameRepositoryProvider` wraps
  the tabs, because two of them read the repository.
