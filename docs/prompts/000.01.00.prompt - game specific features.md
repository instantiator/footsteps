## Game-specific features

There are a number of features, implemented in 2025. that are specific to "Nanny's Magic Trifle" that were implemented at application level, because we were in a hurry.

For instance, the application font is universal - it would be better if a game could specify its own font, and allow the application to use a less 'bubbly' font for its non-game pages.

There may be others. Please review the code base for opportunities to make features game-specific.

## Handlebars / Mustache

We are currently using Mustache as our templating engine. Please switch to Handlebars. This may require selection of a different library. Follow dev-qual guidelines, and propose an appropriate library in the plan. In future, we'll want to be able to use helpers and more complex templating.
