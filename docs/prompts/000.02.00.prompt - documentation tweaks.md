Implement some tweaks to the documentation:

- Render the auto-generated tsdoc code docs as html, ideally with a left/right menu/main layout
- Update `index.md` and `README.md` to reference the new html rendering

## Decisions

- **All of `docs/` is published as HTML**, at `<site>/docs/` on GitHub Pages, so the Markdown pages and the API reference live on one browsable site.
- **VitePress renders the Markdown.** Its default theme gives the left sidebar, right page outline, local search, and dark mode; Markdown stays plain, and VitePress is a devDependency only, with `docs:dev` and `docs:build` scripts.
- **TypeDoc's built-in HTML theme replaces `typedoc-plugin-markdown`.** `docs/tsdoc/` becomes a browsable HTML site (left navigation, main content, right page menu), still regenerated by the pre-commit hook.
- **The docs build runs only in `build:gh-pages`**, assembled into `dist/client/docs/`, so `npm run build` and the local quality gate are unchanged. Dead links in the docs fail the CI Pages build.
- **Links:** `README.md` points at the live site (`https://instantiator.github.io/footsteps/docs/`) and mentions `npm run docs:dev`; `docs/index.md` points at the API reference at `/docs/tsdoc/`.
- **The repository has been renamed to `instantiator/footsteps`.** The remote is updated; the local directory keeps its current name.
- **Branch and commits:** work on `000.02.00-documentation-tweaks`, branched from `main`. One early commit records these decisions and the plan; the implementation lands in one further commit.
