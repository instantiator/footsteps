# Plan: fullscreen and landing page tweaks

- **Branch:** `000.03.00-fullscreen-and-landing-page-tweaks` (from `main`)
- **Commits:** one early commit recording the prompt and this plan, then one commit per stage once its gate passes
- **Orchestrator:** DeepSeek V4.1 Flash. Sub-agent tiers: none — the stages are small and touch overlapping files.

## Context

The landing page lists each game as a bullet with its id and a nested list of credits. This plan makes each game a square tile with a graphic, a description and its id in a grid; moves the credits under per-game headings in the Attributions section; and adds a fullscreen toggle to the game's HUD.

### Decisions taken

| Decision               | Choice                                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| New `GameData` fields  | `description: string` required; `tileGraphic?: string` optional                                                          |
| Graphic reference      | A resource name (key of `resources`), like `imageResource` and `sounds`; checked by `scripts/resource-checks.ts`         |
| Tile without a graphic | Falls back to a plain tinted panel, still a square tile                                                                  |
| Fullscreen target      | `document.documentElement`, via a `useFullscreen` hook                                                                   |
| HUD button visibility  | Always visible, including the title screen, so the HUD bar now always shows                                              |
| Landing structure      | Keep `Local repository`, the status line and the base-URL line; credits move out of tiles and into Attributions          |
| Attribution headings   | `### Footsteps`, then `### <game title>` for each game that has credits                                                  |
| Grid                   | `repeat(auto-fill, minmax(14rem, 1fr))`, `gap: 1rem`, square `aspect-ratio: 1`; about 5 across at 1280px, 1–2 on a phone |
| Branch and commits     | `000.03.00-fullscreen-and-landing-page-tweaks`; prompt and plan early, then one commit per stage                         |

### Constraints and reuse

- Non-negotiables from `dev-qual/agents-files/remote/AGENTS.md`: no unrequested abstractions, zero lint/typecheck warnings, no `any`.
- `resolveResources` (`src/providers/GameDataProvider.tsx`) moves verbatim to `src/util/ResourceUtils.ts` and is imported by the provider and the tile.
- `getBaseURL` and `resolveRelativeURL` (`src/util/ObjectUtils.ts`) do the resolution.
- `GameRepositoryContext` gives the landing components the repository and its source.
- Existing HUD button styling (`padding: 5`, `fontSize: "0.75em"`) carries over to the fullscreen button.
- Prerendering runs in Node with no `window` or `document`: resource resolution stays behind `repository.ready`, and the fullscreen hook touches `document` only in effects and handlers.
