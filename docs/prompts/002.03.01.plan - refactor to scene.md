## Context

"Scene" names what a game shows at each point better than "display", and the prompts that follow (002.03.02–.12) add scene modes on top of it. This is a rename only, so behaviour must not change. It touches about 1,000 uses across `src/`, `tests/`, `scripts/`, the game data and `docs/`. It lands alone, before 002.03.02, so later diffs stay readable.

### Vocabulary (rename by meaning, not search and replace)

| Old                                                                                                                                                                                          | New                                                                                                        |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `displays` / `resetDisplay` (game data keys)                                                                                                                                                 | `scenes` / `resetScene`                                                                                    |
| `src/entities/data/displays/`, `GameDisplay*.ts`                                                                                                                                             | `src/entities/data/scenes/`, `GameScene*.ts`                                                               |
| `src/components/core/display/`, `GameDisplay*Component.tsx`                                                                                                                                  | `src/components/core/scene/`, `GameScene*Component.tsx`                                                    |
| `GameDisplayData`, `GameDisplayBase`, `GameResetDisplay`, `GameOverviewDisplay(Purpose)`, `GamePositionInDisplay`, …                                                                         | `GameSceneData`, `GameSceneBase`, `GameResetScene`, `GameOverviewScene(Purpose)`, `GamePositionInScene`, … |
| `DisplayScope`, `getShownDisplays`, `displayKey`, `getDisplayKey`, `displayRuns`, `displayStates`, `overviewDisplay`, `onDisplayEvent`, `DisplayDomEvent`, `displayRoots`, `calc*Display`, … | `SceneScope`, `getShownScenes`, `sceneKey`, … (same pattern)                                               |
| DOM: `data-display-scope`, `data-display-run`, `displayFrame` / `DISPLAY_FRAME_CLASS`                                                                                                        | `data-scene-scope`, `data-scene-run`, `sceneFrame` / `SCENE_FRAME_CLASS`                                   |
| Author-facing targets `.display-foreground`, `.display-background`                                                                                                                           | `.scene-foreground`, `.scene-background`                                                                   |
| Doc anchors, eg. `#ending-with-the-display`                                                                                                                                                  | `#ending-with-the-scene`                                                                                   |

**Leave alone:** the CSS `display` property, "display" as a verb, `HeadsUpDisplay` (the HUD is a platform term), the Fullscreen API and screens, `docs/prompts/`, ADR titles and filenames, and `docs/tsdoc/` (regenerated, not edited).

**Existing "scene" names to check, not rename:** `.gameScene`, the `Scene` / `SceneProps` component in `src/components/core/layout/GameLayersLayout.tsx:117-203`, and `useSceneTransition`, `SceneTarget`, `sceneOf`, `syncScene`, `fadeScene` and `reshapeScene` in `src/components/core/layout/useSceneTransition.ts`. Each reads correctly once displays are called scenes. Fix only comments that still say "display" (eg. `useSceneTransition.ts:210`), and watch for new names clashing with these. For example, `displayOf` in `EffectTargets.ts:76` returns `.gameViewport`, so it becomes `viewportOf`, not `sceneOf`.

**Brief:**
