Create a plan to update the root page layout. This shifts the content into tabs, to make it easier to navigate.

Under most circumstances, the page should fit a laptop screen without scrolling. Tile sizing is already good.

The top heading should use the 👣 emoji as its icon, at the same size as the text.

## Decisions made during planning and review

They take precedence over the mock-up above.

- **Licence:** the repository had no licence file, so GitHub's licence link pointed at the licence report script.
  Footsteps is now released under the MIT license: `LICENSE`, `"license": "MIT"` in `package.json`, and a README
  section. Every dependency's licence is permissive and compatible (MIT, Apache-2.0, BSD-3-Clause, 0BSD,
  Unlicense, and MPL-2.0 OR Apache-2.0).
- **Tab memory:** the chosen tab is kept in the URL hash, replaced rather than pushed, so a reload or a shared link
  opens it without filling the history.
- **Base path:** shown in debug mode at the end of the footer, rather than under the title.
- **Hover:** a game tile glows under the pointer, and under the keyboard's focus.
- **Narrow screens:** the tabs keep to one row that scrolls sideways, and the tiles shrink to fit a panel narrower
  than 14rem. Wider screens keep the tile sizing as it was.
- **Tabs:** the selected tab joins the panel, with no line between them.
