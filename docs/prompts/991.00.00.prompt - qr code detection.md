Prepare a plan to implement QR code detection.

QR code is a feature which can be enabled or disabled per scene. It should be configurable through the game data. Configuration options include:

- start scene as enabled (boolean)
- CSS style to apply to a shape for the currently identified QR code
- auto submit (submit the QR code as the answer to a challenge, so completing the challenge if it contains the correct answer)

A QR code should be read as text, and information about it stored at a known path in the scene's state.

- last known QR code string in this scene
- QR code currently visible in this scene (boolean)
- last known QR code corner positions in this scene

In this way, the last known QR code can be retrieved, as can a flag indicating whether it is visible right now, and the corner positions can be used to render an element over the top of the QR code if required.

Add the following triggers:

- QR code becomes visible
- QR code becomes non-visible
- QR code value changes

Determine which QR code reading library to use following established rules.
