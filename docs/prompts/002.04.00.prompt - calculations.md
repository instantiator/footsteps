Our users will need to know whether they have enough space to play the game, and how they should set up their camera.

Prepare a plan to develop simple planning calculations.

Challenge any of the specs below if necessary (ie. if data is superfluous or insufficient, or doesn't make sense):

Users should provide some basic information:

- the dimensions of the space available
- highest the camera can be raised (if known)
- the range of player heights to support
- if they want some space around the edges of the floor, the minimum size of each margin (left, right, far) around the floor, from the camera's perspective
- if they want some space behind the camera, the minimum margin behind camera to edge of the available space
- any information they can get from the camera about its field of view / dimensions (start with assumed defaults for a standard USB webcam)

Defaults / constants:

- assumed defaults for a standard USB webcam
- max floor dimensions
- acceptable range of player sizes relative to the floor

The calculations:

- recommended dimensions of the game floor
- recommended distance from the game floor to place the camera
- recommended height to raise the camera
- recommended angle to position the camera (ie. degrees down from the horizontal plane)
- recommended margins around the floor, and distance from camera to the wall behind it

Create a new page in the app that the user can use to perform these calculations:

- top: an extremely succinct explanation of the purpose of the page, with an expanding box containing a simple explanation of the calculations
- split into 2 columns
- left (upper): the user provides values
- left (lower): constants / defaults (these can be adjusted)
- right (upper): calculations
- right (lower): isometric illustration with dimensions marked on it (recalculated with the changing values)

Keep the calculations as simple as possible. Stick to basic operations (add, subtract, multiply, divide, raise to the power of, Nth root). (Challenge if you need more operations.)

The user should be able to plug in as few values as possible to get to an answer. It's ok to have a small number of intermediary calculated values that are then used to calculate the final answers.

Safe to assume that the camera can face the floor directly, and its position should be along the centre line of the floor - so giving it a symmetrical view of the floor.
